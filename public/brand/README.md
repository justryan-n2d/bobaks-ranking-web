# Bobaks Ranking brand assets

## Master logo

The canonical logo is `bobaks-ranking-master-logo.svg`. It is copied byte-for-byte from the approved source in the master roadmap repository:

`justryan-n2d/BOBAKS-RANKING-MASTER-ROADMAP-/docs/bobaks-ranking-master-logo.svg`

Use this asset for the visible website brand. The browser icon in `src/app/icon.svg` must stay byte-for-byte identical to the same master SVG. The legacy `bobaks-mark.svg` path is kept as an identical alias for compatibility.

Do not redraw, recolor, stretch, or add a background outside the logo's transparent area. If the approved master changes, update the website copy and browser icon together.
